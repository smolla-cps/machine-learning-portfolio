# Machine Learning Portfolio

A structured collection of machine learning implementations, experiments, and applied analyses covering core supervised and unsupervised learning methods.

The repository emphasizes algorithm understanding, practical implementation, model evaluation, dimensionality reduction, and data-driven analysis across synthetic, tabular, and image datasets.

## Repository Topics

| # | Topic | Main Methods / Focus |
|---:|---|---|
| 01 | [Introduction to Machine Learning](./01-introduction-to-machine-learning) | NumPy foundations, distance measures, classification fundamentals, model evaluation |
| 02 | [Linear Regression](./02-linear-regression) | Linear regression, feature engineering, regression-based classification |
| 03 | [Logistic Regression](./03-logistic-regression) | Logistic regression with scikit-learn and TensorFlow, probability modeling |
| 04 | [k-NN and Instance-Based Learning](./04-knn-instance-based-learning) | k-NN classification, weighted neighbors, distance metrics, regression |
| 05 | [Naive Bayes Classifier](./05-naive-bayes-classifier) | Naive Bayes from scratch, probability estimation, smoothing, log probabilities |
| 06 | [Decision Trees](./06-decision-trees) | Entropy, information gain, classification, regression, overfitting analysis |
| 07 | [k-NN, Naive Bayes, and Decision Tree Comparison](./07-knn-naive-bayes-decision-tree-comparison) | Classical model comparison, tuning, cross-validation, missing-data handling |
| 08 | [Ensemble Methods](./08-ensemble-methods) | Random Forests, Extra Trees, voting, bagging concepts, gradient boosting, XGBoost |
| 09 | [Support Vector Machines](./09-support-vector-machines) | Linear SVM geometry, support vectors, regularization, applied classification |
| 10 | [Principal Component Analysis](./10-principal-component-analysis) | PCA geometry, dimensionality reduction, reconstruction, classification with reduced features |
| 11 | [Clustering](./11-clustering) | Hierarchical clustering, DBSCAN, k-means, dendrograms, outlier detection |

## What This Repository Demonstrates

- Implementation of core machine learning algorithms and concepts
- Supervised learning for classification and regression
- Unsupervised learning and clustering
- Dimensionality reduction with PCA
- Ensemble learning and model combination
- Feature engineering and preprocessing
- Hyperparameter analysis and model comparison
- Evaluation using accuracy, confusion matrices, MSE, MAE, and related metrics
- Algorithm behavior through synthetic examples and real datasets
- Visualization and interpretation of model results
