# Water Potability Dataset

`water_potability.xlsx` contains 2,011 complete observations used by the SVM classification notebook.

## Columns

| Column | Role |
|---|---|
| `ph` | predictor |
| `Hardness` | predictor |
| `Solids` | predictor |
| `Chloramines` | predictor |
| `Sulfate` | predictor |
| `Conductivity` | predictor |
| `Organic_carbon` | predictor |
| `Trihalomethanes` | predictor |
| `Turbidity` | predictor |
| `Potability` | binary target |

Class distribution:

- not potable (`0`): 1,200 observations
- potable (`1`): 811 observations
